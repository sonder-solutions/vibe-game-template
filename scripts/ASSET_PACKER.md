# Asset Packer

Maximal Rectangles bin packing algorithm for sprite sheets.

## Usage

```bash
# Pack assets from assets/input to assets/output
npm run pack-assets

# Or specify custom paths
npx tsx scripts/pack-assets.ts assets/input assets/output
```

## How It Works

1. Scans input directory for images (PNG, JPG, GIF, WebP)
2. Sorts images by area (largest first)
3. Uses Maximal Rectangles algorithm to pack efficiently
4. Allows 90° rotation for better space utilization
5. Generates:
   - `sprites.png` - Single sprite sheet with all images
   - `sprites.json` - Map with frame positions and metadata

## Output Format

```json
{
  "meta": {
    "image": "sprites.png",
    "size": { "w": 1024, "h": 1024 }
  },
  "frames": {
    "player.png": {
      "frame": { "x": 0, "y": 0, "w": 32, "h": 32 },
      "rotated": false,
      "trimmed": false,
      "spriteSourceSize": { "x": 0, "y": 0, "w": 32, "h": 32 },
      "sourceSize": { "w": 32, "h": 32 }
    }
  }
}
```

## Loading in Game

```typescript
// Load sprite sheet and JSON
const sheet = await loadImage('assets/output/sprites.png');
const data = await fetch('assets/output/sprites.json').then(r => r.json());

// Extract a frame
function getFrame(name: string) {
  const frame = data.frames[name].frame;
  return {
    image: sheet,
    sx: frame.x,
    sy: frame.y,
    sw: frame.w,
    sh: frame.h
  };
}

// Draw a frame
const player = getFrame('player.png');
ctx.drawImage(
  player.image,
  player.sx, player.sy, player.sw, player.sh,
  x, y, width, height
);
```

## Algorithm Details

**Maximal Rectangles** - A bin packing algorithm that:
- Maintains list of free rectangular spaces
- Places items in best-fit position (smallest leftover space)
- Splits remaining space into maximal rectangles
- Removes redundant rectangles

**Benefits:**
- Fast packing (near real-time)
- Good space utilization (typically 80-95%)
- Handles rotation for better packing
- Simple implementation

## Directory Structure

```
assets/
  input/          # Your source images
    player.png
    enemy.png
    coin.png
  output/         # Generated by packer
    sprites.png   # Sprite sheet
    sprites.json  # Frame map
```

## Notes

- Images can be rotated 90° for better packing (check `rotated` flag in JSON)
- Bin size is automatically calculated based on total image area
- Minimum bin size is 256x256
- Supports PNG, JPG, GIF, WebP formats
